CityResQ
城市災害韌性分析平台

A GIS-Based Urban Disaster Risk and Resource Accessibility Analysis Platform Using Open City Data

基於公開城市資料與 GIS 空間分析之城市災害風險與資源可及性研究平台。從真實的城市與社會問題出發，蒐集公開資料，透過資料清理、資料庫、GIS 空間分析、統計分析與視覺化，研究災害風險、人口分布與公共資源配置之間的關係，並以互動式網站呈現研究成果。

研究聲明：本平台所有資料須記錄來源、時間、格式與更新時間，不虛構資料。分析結果僅為研究模型，不代表官方災害預測。網站只呈現「根據本研究所建立的指標與公開資料，此區域呈現較高的相對風險值」，不宣稱「這裡就是最危險的區域」。

RESEARCH METHODOLOGY研究方法

從提出問題到得出結論：提出問題 → 蒐集資料 → 分析資料 → 建立方法 → 驗證結果 → 發現問題 → 得出研究結論

風險指標概念：Hazard（災害危險程度）、Exposure（人口或城市暴露程度）、Vulnerability（脆弱程度，如高齡人口比例）、Accessibility（公共資源可及性）。各指標標準化後再組成綜合風險指標。
敏感度分析：模型 A（災害權重較高）、模型 B（人口權重較高）、模型 C（可及性權重較高）。檢驗權重改變時風險排名的變化，以及哪些區域在所有模型下都維持相對高風險。
可及性：第一階段使用直線距離與簡單空間分析，之後視需要加入道路網路與實際行走距離。

TECH STACK技術架構

先完成可運作的 MVP，再逐步升級，不一開始使用過多複雜技術。

關於 AI 與機器學習：不為了「看起來有 AI」而加入。第一階段先完成 資料 → GIS → 統計分析 → 風險模型。之後若使用聚類、分類、回歸、特徵分析或異常值偵測，必須說明使用的資料、特徵、目標變數、選擇理由、訓練與驗證方式，以及模型限制。
